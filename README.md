# موقع Valk

موقع ثابت (HTML/CSS/JS بدون سيرفر وبدون بناء) — يشتغل على أي استضافة ملفات: GitHub Pages، Netlify، Cloudflare Pages، أو أي استضافة عادية.

## الرفع
1. ارفع محتويات هذا المجلد كما هي (index.html بالجذر).
2. افتح `js/config.js` وحط روابطك: `inviteUrl` (إضافة البوت)، `supportUrl` (سيرفر الدعم)، `chessUrl`. الرابط الفارغ يظهر كزر «قريباً».

## التعديل
- المميزات والأوامر: `js/data.js` (status: "ok" فقط لما الميزة تنبني فعلاً، وإلا "soon").
- التحديثات: تتولّد من البوت: `python3 tools/build_updates.py مسار_مجلد_البوت` (يكتب `js/updates.js`).
- الفيديو: `assets/valk_intro.mp4` (الصورة الأولى `assets/poster.jpg`).
- الألوان: متغيرات `:root` بأول `css/style.css`.

## ملاحظات
- الخط Tajawal من Google Fonts (إذا ما تريد اتصال خارجي، احذف سطر الـ link من الصفحات؛ يرجع لخط النظام).
- ما اكو لوحة تحكم (dashboard) بهذي النسخة: الموقع تعريفي (مميزات، أوامر، تحديثات، دعم). لوحة التحكم تحتاج سيرفر وتسجيل دخول وAPI من زرزور.


## ⚙️ ملف الإعدادات (مهم)
`js/config.js` فيه روابطك (إضافة البوت، الدعم...) وما ينحط بالـ zip حتى ما ينمسح عند فك الضغط فوق موقعك.
إذا موقعك جديد: انسخ `js/config.example.js` باسم `js/config.js` وعبّي الروابط.
